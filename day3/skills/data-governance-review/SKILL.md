# Data Governance Review

When reviewing a data governance scenario, ALWAYS produce the following
five sections in exactly this order.

## Required output format

### 1. Issue

State the main governance issue in 1-2 sentences.

### 2. Governance Area

Name the primary applicable governance area.

### 3. Risk / Gap

Describe the main risk or missing control in 2-3 sentences.

### 4. Required Action

List the actions required to address the identified gap.

### 5. Recommendation

Provide ONE practical recommendation.

## Rules

- These five sections are mandatory.
- Use exactly these section titles.
- Do not add any other sections.
- Do not rename the sections.
- Do not include separate sections such as Risks, Recommendations,
  Expected Outcomes, Current State, or Next Steps.
- Distinguish confirmed requirements from recommendations.
- Do not claim compliance without sufficient evidence.
- Do not invent laws, regulations, policies, or organizational requirements.
- If information is insufficient, explicitly state what information is missing.
- Keep the response concise and professional.
